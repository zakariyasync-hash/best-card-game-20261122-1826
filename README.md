Ember Court is a turn-based card duel against Asha, the Cinder Queen. Each round refills 3 energy; spend it on 16 original cards across four suits — Flame, Leaf, Wave and Stone, each told by colour and glyph — to deal damage, raise shields, heal and draw, and take her 24 hearts to zero before she takes yours. The rival reads the table and answers in kind: hurt, she heals; ahead, she presses. Static files only, no network, played with mouse or keyboard (keys 1–7 play a card, Enter ends the turn).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
